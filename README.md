# To-Do List Application

## Project Overview
This is a console-based To-Do List Application developed using Python as part of my Python Developer Internship.

The application helps users manage their daily tasks by allowing them to add, view, and remove tasks.

## Features
- Add new tasks.
- View all available tasks.
- Remove tasks by selecting their task number.
- Save tasks in a text file.
- Load previously saved tasks when the application starts.
- Handle invalid user inputs.

## Technologies Used
- Python
- Visual Studio Code

## Concepts Used

- Conditional Statements

- Exception Handling

## How to Run the Application

1. Install Python on your system.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

   python todo.py

5. Select an option from the displayed menu.

## Application Menu

1. Add Task
2. View Tasks
3. Remove Task
4. Exit
